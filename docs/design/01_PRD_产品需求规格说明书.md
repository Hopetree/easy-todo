# 01_PRD_产品需求规格说明书

**项目名称**：Easy Todo（浏览器插件 TODO 管理器）

---

## 一、项目概述

Easy Todo 是一款浏览器插件形式的 TODO 任务管理工具，面向个人用户的日常任务管理需求。支持多列表管理、丰富任务属性、关键词搜索与字段筛选，并提供完整数据的导出/导入功能以实现数据持久化。

---

## 二、目标用户

- **主要用户**：个人用户，用于日常任务管理
- **使用场景**：工作待办追踪、个人生活计划、学习任务清单等

---

## 三、核心功能

### 3.1 TODO 任务管理（CRUD）

单个任务包含以下属性：

| 属性 | 类型 | 说明 |
|------|------|------|
| 标题 | 文本 | 必填，任务描述 |
| 完成状态 | 布尔 | 已完成 / 未完成 |
| 优先级 | 枚举 | 高 / 中 / 低 |
| 截止日期 | 日期 | 可选，任务截止时间 |
| 分类标签 | 标签数组 | 可选，支持多个标签 |
| 备注 | 文本 | 可选，任务详细说明 |
| 进度 | 数字 | 0-100，新建默认 0，完成自动 100% |
| 归档状态 | 布尔 | 已归档 / 未归档，默认未归档 |
| 挂起状态 | 布尔 | 已挂起 / 未挂起，默认未挂起 |
| 排序序号 | 数字 | 手动拖拽排序用，新建插入到列表顶部 |

操作：创建、查看、编辑、归档（软删除）、永久删除、还原任务；切换完成状态；切换挂起状态；拖动排序。

### 3.2 多列表管理

- 支持创建多个独立列表（如"工作"、"个人"、"学习"等）
- 每个列表包含各自的任务集合
- 支持列表的创建、重命名、删除
- 列表支持拖拽排序，持久化排序结果

### 3.3 任务进度

- 每个任务有 0-100 的进度值
- 新建任务默认 0%，标记完成自动设为 100%，取消完成重置为 0%
- 编辑任务时可拖动滑块调整进度
- 任务卡片显示绿色进度条

### 3.4 任务归档

- 任务列表中每个任务提供"归档"按钮（替代原删除按钮），归档后任务从主列表移除
- 主视图默认不显示已归档任务，可通过筛选栏切换
- **归档任务页面**：顶部导航栏点击归档图标进入独立页面
  - 展示所有已归档任务，显示来源列表名称和颜色标识
  - 支持关键词搜索和按列表筛选
  - 支持复选框批量选择，批量还原或批量永久删除
  - 支持导出归档任务为 CSV
  - 永久删除需要二次确认
  - 删除列表时，列表下的任务自动归档而非永久删除
- 已归档任务不显示在周报中

### 3.5 拖拽排序

- 任务和列表均支持拖拽重排
- 排序规则：未完成在前 → 未挂起在前 → 手动拖拽顺序 → 优先级（高→中→低）→ 更新时间倒序

### 3.6 周报生成

- 顶部导航栏点击剪贴板图标进入独立周报页面
- 自动生成周报文本：按列表分组，列出任务标题和进度百分比
- 已归档和已挂起任务不显示在周报中
- 支持"重新生成"按钮刷新内容
- 周报文本可编辑（textarea 自动撑高适应内容）
- 一键复制到剪贴板，复制成功后按钮显示"已复制"反馈

### 3.7 搜索与筛选

- **关键词搜索**：按任务标题/备注内容进行全文搜索
- **字段筛选**：按优先级、完成状态、归档状态、挂起状态、标签等字段组合筛选
- 默认筛选未归档任务
- 搜索与筛选可同时使用
- 标签筛选仅显示当前未归档任务的标签集合

### 3.8 任务挂起

- 每个任务提供暂停/播放按钮，用于标记任务为"挂起"状态
- 挂起的任务：在任务列表中显示橙色"已挂起"标签
- 挂起不影响排序：未挂起任务优先排在已挂起任务之前
- 挂起的任务不显示在周报中
- 编辑任务时可勾选"已挂起"
- 筛选栏支持按挂起状态筛选：全部（含挂起）/ 未挂起 / 已挂起

### 3.9 设置页面

- 顶部齿轮图标进入设置
- 配置项：默认展开详情、默认优先级、默认筛选视图、删除前确认
- 精简设计，仅保留偏好设置，数据管理功能迁移至独立页面

### 3.10 数据管理页面

- 顶部导航栏点击下载图标进入独立数据管理页面
- 提供完整数据导入/导出功能，入口集中
- 详情见 3.11

### 3.11 数据导入/导出

- **导出 JSON**：将所有列表及任务数据导出为 JSON 文件，用于备份
- **导出 CSV**：将全部任务导出为 CSV 文件（也可在归档页面导出归档任务 CSV）
- **导入 JSON（文件）**：从文件选择器加载 JSON 文件并解析
- **导入 JSON（粘贴）**：在数据管理页面可展开手动粘贴区域，直接粘贴 JSON 文本并解析
  - 解析支持详细错误提示（JSON 语法错误位置、数据完整性校验）
  - 导入前对数据做规范化处理，防御旧版本/损坏数据
- **导入模式**：合并（追加不冲突的 ID）或覆盖（完全替换），覆盖模式保留当前版本号
- 入口位于数据管理页面

## 五、功能边界（明确不做）

- ❌ 云同步 / 多端同步
- ❌ 多用户协作 / 分享功能
- ❌ 推送通知 / 到期提醒
- ❌ 子任务 / 依赖关系
- ❌ 附件 / 图片上传
- ❌ Markdown 渲染（纯文本处理）

---

## 六、非功能性需求

- **离线运行**：所有功能在浏览器本地完成，无需网络
- **数据安全**：数据存储在浏览器本地存储中
- **性能**：任务列表操作响应时间 < 100ms
- **兼容性**：支持 Chrome、Edge 等主流 Chromium 内核浏览器
